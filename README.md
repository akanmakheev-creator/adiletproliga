# Adilet Pro Liga — Школьный футбол

SofaScore-inspired мобильная статистика: таблица, команды, матчи, бомбардиры/ассистенты + защищённая админ-панель.

## Запуск

```powershell
cd C:\Users\User\Desktop\bvb
npm start
# открыть http://localhost:3000
```

Переменные окружения:

- `PORT` — порт (по умолчанию 3000)
- `ADMIN_PASSWORD` — пароль администратора (по умолчанию `adilet2026`)

## Что внутри

- `server.js` — Node.js (без зависимостей): статика + REST API + централизованный подсчёт статистики + файловое хранилище `data/db.json`.
- `public/` — SPA (мобильная навигация: Таблица / Команды / Матчи / Статистика), русские подписи, тёмная/светлая тема.
- Админка: `#/admin` — вход по паролю, токен Bearer, все записи проверяют авторизацию **на сервере**.

## Выкладка в интернет (чтобы работало у всех)

Важно: Netlify умеет показывать только картинки/текст, а наша база и вход админа живут в `server.js` (Node). Поэтому так:

**Вариант 1 — всё целиком на Render (рекомендую, 5 минут):**
1. Залей папку в GitHub.
2. На render.com: New → Web Service → выбери репозиторий.
3. Start Command: `npm start`, Environment: `ADMIN_PASSWORD=твой_пароль`.
4. Готово: сайт + база работают по выданной ссылке.

**Вариант 2 — фронт на Netlify + бэкенд на Render:**
1. Render как в варианте 1 (это бэкенд, например `https://apl.onrender.com`).
2. В `public/index.html` перед строкой `<script src="/js/app.js"` добавь:
   `<script>window.APL_API_URL="https://apl.onrender.com"</script>`
3. На Netlify: Publish directory = `public` (файл `netlify.toml` уже лежит в проекте).

Без запущенного бэкенда матчи/игроки сохраняться не будут — 404 на Netlify как раз из-за неверной Publish directory или отсутствия бэкенда.

## QA-сценарий (пройден)

1. Вход → 2. создать игроков → 3. матч → 4. гол+ассист → 5. публикация → 6. проверка таблицы/бомбардиров/профилей → 7. правка/удаление → 8. участия → 9. перезагрузка и второй клиент.

## Данные

- Счёт матча = число событий гола за команду (источник правды — `match_events` с уникальными ID, идемпотентный пересчёт).
- Матчи игроков считаются только из отметок участия, либо вручную (override, помечается в профиле).
- В таблицу попадают только `completed` матчи. Очки и сортировка настраиваются в админке.
